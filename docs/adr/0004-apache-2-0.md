# ADR 0004 — Apache 2.0 license for all public repos

**Status:** Accepted
**Date:** 2026-05-15

## Context

License choice locks the legal terms under which contributions can be made and downstream users can build on the project. Relicensing later requires consent from every contributor — including ex-teammates who may be unreachable. Picking the wrong license at commit 1 has historically been a catastrophic mistake (multiple high-profile projects have abandoned attempts to switch from MIT to Apache or vice versa).

Robotics-specific consideration: patent grants matter. A permissive license without an explicit patent grant (e.g., MIT, BSD) leaves users exposed to contributor patent claims later. Apache 2.0 includes an explicit, irrevocable patent grant from contributors.

ROS2 ecosystem consideration: the bulk of ROS2 core (rclcpp, rclpy, message generators, common navigation packages) ships under Apache 2.0. Matching the ecosystem reduces friction for downstream relicensing analysis.

## Decision

**Apache License 2.0** for all public Custos repositories. The full text lives in `LICENSE` at the root of every public repo.

The proprietary `custos-novatek-sdk-wrapper` repo uses an "All Rights Reserved" notice instead, because the third-party SDK it wraps prohibits redistribution. See ADR 0010 for that boundary.

## Consequences

**Positive:**
- Explicit patent grant protects downstream users.
- Compatible with the rest of the ROS2 ecosystem.
- Permissive: encourages commercial adoption without forcing source release of downstream changes.

**Negative:**
- No copyleft. Companies can embed Custos in proprietary products without contributing back. This is the explicit tradeoff for adoption breadth; the project does not currently want to enforce copyleft.
